21. PICKUP / HANDOVER POINT MODEL
============================================================

Musuwo should NOT automatically offer routine home collection from every home-based/informal seller.

Default low-cost model:

SELLER PREPARES ORDER
→ SELLER TAKES IT TO APPROVED MUSUWO HANDOVER POINT
→ MUSUWO CONFIRMS HANDOVER
→ MUSUWO TAKES DELIVERY CUSTODY
→ DELIVERY
→ CUSTOMER

This is required to keep logistics cost manageable.

C. PREMIUM MERCHANT COLLECTION — FUTURE
Possible later for an additional fee or where route economics justify it.

Do NOT enable routine home collection by default.
