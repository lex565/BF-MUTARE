MUROORA SME MARKETPLACE EXPANSION — COMPLETE CODEX IMPLEMENTATION PROMPT

ROLE

You are extending the EXISTING Muroora platform into a controlled SME marketplace that supports multiple business types beyond ordinary retail.

This is a continuation of what has already been built.

DO NOT rebuild Muroora from scratch.
DO NOT create a separate backend.
DO NOT create a second Supabase project.
DO NOT create duplicate customer, merchant, order, chat, rider, staff, inventory, or authentication systems.

The EXISTING Muroora backend remains the source of truth.

These new features must be available in BOTH:
1. THE EXISTING WEB APPLICATION
2. THE EXISTING CUSTOMER MOBILE APPLICATION

Merchant/business management may initially use a responsive web portal if that is simpler and safer, but customer discovery, search, business pages, listings, enquiries, chat, and contact-release flows must work coherently across both web and mobile.

The platform is moving from:
MUROORA MART
→ DELIVERY
→ CUSTOMER APP
→ STAFF / RIDER OPERATIONS

toward:
MUROORA SME MARKETPLACE

The focus is SMALL TO MEDIUM ENTERPRISES.

The goal is to make it easy for a Zimbabwean SME to join Muroora without needing:
- its own website
- its own mobile app
- advanced e-commerce knowledge
- delivery infrastructure
- search/SEO expertise
- complicated technical setup

The platform should remain SIMPLE.

============================================================
2. CORE PLATFORM IDEA
============================================================

Muroora should no longer assume every business is a grocery store.

All approved businesses share a common BUSINESS identity.

Then the platform activates the correct tools based on what that business offers.

Conceptually:

BUSINESS
→ BUSINESS TYPE
→ CAPABILITIES
→ LISTINGS
→ CUSTOMER DISCOVERY
→ COMMERCE / ENQUIRY / BOOKING

Initial business types should support:
1. RETAIL
2. FOOD / TAKEAWAY / RESTAURANT
3. ACCOMMODATION / BOARDING HOUSE
4. SERVICES
5. EDUCATION / TUTORS
6. BEAUTY / PERSONAL CARE
7. AUTOMOTIVE
8. HOME SERVICES
9. OTHER SME CATEGORY

Do not make the category architecture rigid.
Admin should be able to add/edit categories later.

============================================================
3. THREE CORE INTERACTION MODES
============================================================

Do NOT force every business into the same transaction flow.

MODE 1 — COMMERCE
For groceries, books, food, retail products and other direct purchases.

Flow:
Product / Menu Item
→ Cart
→ Checkout
→ Fulfilment
→ Delivery / Pickup

MODE 2 — LEAD / ENQUIRY
For boarding houses, tutors, plumbers, photographers and service providers.

Flow:
Listing
→ Muroora Chat
→ Customer expresses interest
→ Business responds
→ Controlled contact release
→ Customer and business continue where appropriate

MODE 3 — BOOKING / REQUEST
For future appointment-based services.

Examples:
- barber
- tutor
- photographer
- service appointment

Do not build a giant booking engine unless required now.
Prepare clean extension points.

============================================================
83. FINAL PRODUCT PRINCIPLE
============================================================

Muroora should become easy enough that a small Zimbabwean business owner can join without understanding technology.

Business owner:
TELL MUROORA ABOUT MY BUSINESS
→ GET VERIFIED / APPROVED
→ CREATE MY STORE / LISTINGS
→ RECEIVE ORDERS OR ENQUIRIES
→ COMMUNICATE WITH CUSTOMERS
→ IMPROVE USING MUROORA INSIGHTS
→ CONTINUE AFTER A FAIR PILOT

Customer:
SEARCH WHAT I NEED
→ FIND TRUSTWORTHY LOCAL OPTIONS
→ BUY / CHAT / ENQUIRE
→ USE MUROORA AS THE GATEWAY
→ RECEIVE DELIVERY OR CONNECT SAFELY

Different SME realities must be supported without forcing everyone into the same model.

RETAIL = COMMERCE
FOOD = COMMERCE
ACCOMMODATION = VERIFIED LEADS / ENQUIRIES
SERVICES = LEADS / BOOKINGS
EDUCATION = LEADS / BOOKINGS

Muroora Mart remains the original operating merchant, but it must not define the architecture of the entire platform.

The long-term goal is:

A Zimbabwe-focused local business discovery, commerce, enquiry and delivery platform built around verified SMEs, useful search, controlled trust, practical customer access and measurable value to participating businesses.
