MUSUWO APP — MASTER CODEX BUILD PROMPT
PINDUODUO-INSPIRED STRUCTURE, USING THE EXISTING MUSUWO/MUROORA ARCHITECTURE
REVISED DELIVERY MODEL: MUSUWO HANDLES DELIVERY, MERCHANT BRANDING REMAINS CUSTOMER-FACING

IMPORTANT:
THIS IS A CONTINUATION OF THE EXISTING PROJECT.

DO NOT REBUILD FROM SCRATCH.
DO NOT REMOVE OR REPLACE THE STRUCTURE ALREADY CREATED.
DO NOT CREATE A SECOND BACKEND.
DO NOT CREATE A SECOND SUPABASE PROJECT.
DO NOT DUPLICATE AUTH, ORDERS, INVENTORY, CHAT, MERCHANTS, DELIVERY, RIDERS, CUSTOMERS OR ANALYTICS.

The purpose is to create MUSUWO as the parent marketplace platform with a discovery-first structure inspired by Pinduoduo, while keeping everything already established.

Musuwo should be:
- discovery-first
- category-led
- social-commerce friendly
- low-friction
- merchant-based
- mobile-first
- web-enabled
- simple enough for Zimbabwean users
- useful to small and medium enterprises
- future-ready for group buying and delivery at scale

Pinduoduo is inspiration for MARKETPLACE STRUCTURE only.

Do NOT clone Pinduoduo's UI, wording, graphics, exact ranking systems, gamification, or China-specific payment assumptions.

6. MUSUWO DELIVERY ARCHITECTURE
============================================================

Concept:

CUSTOMER
→ buys from a merchant on Musuwo
→ merchant receives order
→ merchant prepares order
→ merchant marks order READY
→ MUSUWO DELIVERY takes custody
→ Musuwo assigns appropriate delivery handling
→ customer receives merchant-branded tracking
→ delivery completed
→ custody closes
→ order completes

Shared delivery infrastructure should support all eligible commerce merchants.

Do NOT build one separate delivery engine per merchant.

61. FINAL PRODUCT PRINCIPLE
============================================================

MUSUWO = THE PLATFORM

MUROORA MART = FOUNDING MERCHANT

OTHER SMEs = MERCHANTS / LISTING PROVIDERS

MUSUWO = DELIVERY INFRASTRUCTURE

MERCHANT BRAND = CUSTOMER-FACING ORDER / DELIVERY BRAND

PUBLIC RIDER RECRUITMENT = COMING SOON

Musuwo should feel like:

OPEN APP
→ DISCOVER
→ SEARCH
→ FIND LOCAL BUSINESSES / PRODUCTS / FOOD / ROOMS / SERVICES
→ SHOP OR ENQUIRE
→ MUSUWO COORDINATES THE PLATFORM AND DELIVERY
→ CUSTOMER STILL EXPERIENCES THE BRAND THEY CHOSE TO BUY FROM

The customer should never feel that every merchant has been erased behind the Musuwo brand.

Musuwo is the infrastructure and marketplace.

The merchant remains the merchant.
